# nanotech@surfaces — Empa

This GitHub organization hosts software developed by the nanotech@surfaces laboratory at Empa and its collaborators. It brings together tools for computational materials research, scanning probe microscopy, experimental data analysis, and scientific data management.

The repositories include AiiDA plugins and workflows, AiiDAlab applications, post-processing and visualization libraries, infrastructure configuration, and research and teaching examples.

[Browse all repositories](https://github.com/orgs/nanotech-empa/repositories)
